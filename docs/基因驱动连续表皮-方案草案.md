# 基因驱动连续表皮：方案草案

日期：2026-09-08。

**2026-09-09 最新授权：用户已要求将本草案与阶段 2B、2C 一起交给开发 agent 完成。本文转为实施依据；旧的暂不派发和中途人工验收安排已被替代。由主 agent 做简短初验后停止，用户稍后统一检查。**

## 1. 推荐结论

针对本项目现有代码与低模群落目标，推荐“统一模拟几何描述 + 连续参数骨架 + 受连接约束的隐式表皮 + 缓存网格/姿态形变”。这是一项工程权衡，不是所有项目的普遍最优算法。

不把六种样本做成六个由基因选择的模型。球、卵圆、杆、弯曲丝、扁平和分枝应是同一连续参数空间的不同结果。外观不仅由基因决定，还由真实发育程度和当前物理姿态决定。

## 3. 当前缺口

正式世界 `LowPolyWorldRenderer` 仍按 `BodyVisualRegion` 的尺寸/角度显示共享 SphereMesh。

样本台 `MorphologyLab` 调用 `BuildArtificialSamples()`，其 `OrganicSegment` 只有端点/半径/垂直比例；缺少稳定区域归属、连接图、绑定权重、完整遗传映射。`OrganicMeshGenerator` 已有隐式采样与 marching tetrahedra，可作为原型复用，不能直接给每个个体每帧调用。

此外，Godot 的 `ArrayMesh.GetSurfaceCount()==1` 只代表一个渲染 surface，不证明网格是拓扑连通的。正式验收需检查焊接顶点后的三角形连通分量、边界边与退化三角形。

## 4. 单一几何来源

推荐数据路径：

`Genome → Development → BodyGeometry（静止结构） + BodyPose（当前姿态） → 模拟暴露/体积/接触与显示表皮分别消费`

BodyGeometry 位于纯 C# 核心或无 Godot 的共享程序集。包含稳定 RegionId、父连接、局部中心线/截面、组织体积、外表面归属、连接半径和材料权重；不含 Mesh、材质或场景节点。

BodyPose 包含实际求解出的区域位置、角度和收缩状态。新生体只显示已付费长出的区域，不能提前显示成年完整模型。区域 ID 不能随缓存数组排序改变。

颜色和粗糙度可由已有色素/表面材料导出；不每次渲染随机抽颜色。分辨率、网格误差与LOD属于显示配置，不能写成基因并参与进化。

## 5. 从基因到形态

先映射现有长度、宽度、相对角度、父连接和发育成熟度，新增参数仅在无法表达目标时引入：显式厚度比例、端部渐细、静止曲率、连接过渡宽度、可选圆润度。

厚度不应继续由“密度”直接替代。密度决定质量/体积关系，厚度比例控制三轴分配；改变比例后以已支付物质/密度归一化体积。新增参数须进入复制、突变、校验、指纹及成本，旧基因提供中性默认值和版本说明。

| 连续条件 | 几何结果 |
|---|---|
| 中心线趋近零长度、三个半轴接近 | 球 |
| 主轴增长、两端平滑收口 | 卵圆/杆 |
| 沿中心线平滑改变切向 | 弯曲丝 |
| 垂直半轴缩短、平面截面展开 | 扁平 |
| 父子拓扑分叉，连接截面连续 | 分枝 |

初版保留现有2.5D静止拓扑，厚度表达3D体积；不要假称已允许任意三维发育。小参数突变应产生小几何差异，离散的拓扑突变允许结构变化。

## 6. 表皮生成与运动

### 静止表皮

无分枝长链可用截面扫掠，单区域直接参数曲面；分枝和复杂接头采用骨架隐式场。无论生成算法，必须逼近同一份 BodyGeometry，而不是为不同LOD重新解释生物结构。

仅在存在真实组织连接的接头邻域允许平滑过渡；未连接枝条即使靠近也不焊死。不同个体永不共用融合场。场值与距离场应区别命名：现有势场不一定是真正SDF，不能默认梯度长度恒为1或直接按SDF步长推进。

提取后进行顶点焊接、退化面清理、方向一致性检查和受误差约束的减面。薄枝需按局部尺度采样或使用扫掠后备方案，不能因统一低分辨率网格丢掉已存在的身体区域。

### 运行时变形

网格生成时记录顶点与局部区域/连接的绑定权重，优先在邻接区域间分配权重。每模拟帧只上传真实姿态，由插值与蒙皮显示；不每帧重跑体素提取。

MVP近景可先用有限影响数的线性绑定，并监测关节体积塌陷；需要时只对选中对象加局部表面投影修正。双四元数适合刚性旋转，但本项目还有非均匀生长/缩放，不能不处理尺度就直接换用。

生长改变已有区域尺寸可连续形变；新增/删除区域或连接变化才重建拓扑。禁用视觉动画时模拟状态应完全相同。

## 7. 与模拟保持一致

表皮融合带来的额外显示体积受容差约束；不能把重叠区域体积直接相加，又把融合外壳当同一物质量。物理主模型采用确定性的区域体积/连接修正，近景封闭网格体积作为交叉检查，不用显示网格每帧反向驱动物理。

暴露判定与显示表面都引用同一外界连接边界；视觉缝隙不能等同于真实呼吸通道。独立显示LOD不得改变氧交换、损伤、碰撞或适应实验结果。

注意拓扑“一个皮肤连通体”与图“区域都能传物质”不是一回事：皮肤相连但内部运输边导通不足仍可能缺氧。

## 8. 批量渲染策略

一个 MultiMesh 只能共享一种网格；不同拓扑不能假装放入同一MultiMesh。常见静止形态按几何键缓存并批量实例化，近景动态身体采用受控数量的独立实例/姿态缓冲；MVP先以共享区域代理覆盖远景，避免构建重型GPU蒙皮基础设施。

缓存键：几何版本、规范化形态描述、显示生长档、LOD；不能直接只用物种ID，也不要把与外形无关的全部控制基因放入键造成重复。碰撞处理后的最终几何描述应参与键。

量化仅用于远景显示近似，选中对象保留真实连续参数。缓存带内存/条目/同时构建数上限；出生与结构变异只入有界队列，未完成时显示可靠代理；淘汰不能销毁仍被实例引用的资源。

建议试验目标：普通对象80–320三角形，近景400–1200，单个选中对象1200–3000；总预算优先于逐个体目标。以投影尺寸和滞回切换LOD，不按固定世界距离一刀切。上述数字未实测，不是性能承诺。

## 10. 接入验收

- 六种样本通过真实Genome/Development生成，人工覆盖基因与自然演化样本明确区分；不是匹配名称后切换六个模型。
- 相同基因与相同发育状态输出相同规范化几何；不同年龄在实际物质支持范围内发育。
- 长宽/曲率小变异连续改变轮廓；结构复制/删除的前后几何可追溯到亲子差异。
- 连接检查采用几何邻接/连通分量，不以Godot surface数替代；分枝接头闭合，未连接枝条不粘连。
- 封闭网格体积与模拟物质量/密度关系在声明容差内；细枝和连接不因LOD丢失为不同生态实体。
- 动态表皮与真实区域姿态一致；相机/显示LOD/皮肤生成开关不影响同版本模拟指纹。
- 实测批次数、缓存峰值、构建耗时和选中对象响应。不得拿论文的单角色帧率保证本项目群落性能。
