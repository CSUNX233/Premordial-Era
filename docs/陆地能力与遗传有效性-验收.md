# 陆地能力与遗传有效性

## 验收目标

分别验证功能附肢能产生实际陆地位移、空气交换能满足真实耗氧、水储备充足时不会仅因处于陆地触发避害，以及陆地出生的后代能继承相同能力并付费发育。

人工能力样本用于检查模拟规则，不作为自然突变已经产生陆生物种的证据。正常模式仍从初级水生祖先开始。自然陆生适应需要真实谱系、陆地生存与繁殖、遗传差异及对照，不能用人工样本替代。

## 避害修正

旧版将含水低于 0.90 普遍计为危险，并把环境维护代价直接当作逃离信号；该代价还混有压力成本。现在按真实缺氧、水储备不足和新损伤判断，不因正常支付维护成本就逃。含水 0.70 以下才开始连续增加缺水压力，器官有无不直接免疫实际缺氧。

输入隔离检查：含水 0.80、供氧正常时，陆地与水中的生理压力均为 0；含水降至 0.40 或真实供氧不足时触发压力。原沿岸急性回撤对照仍通过。

## 湿土补水

陆地新增独立的有限土壤水库存，按种子地形、原湿度和真实网格面积初始化。空气湿度仍只影响蒸发；土壤水势随库存耗尽下降，不会自动补满。水独立于有机物/矿物账，不会被当作食物。

身体贴地的下表面或实际承重落足可通过已表达的交换组织吸水，通透性、接触面积、交换距离与水势差共同决定通量。身体抬离地面后不能隔空吸水。水进入局部区域，再由原运输连接分配；吸收多少，土壤就扣除多少。

`--diagnose-soil-water` 已通过：接触样本 5 秒吸收 0.1819 单位水；悬空、交换失活、耗干土壤均为 0；竞争不能透支同一库存，水量误差 `4.62e-14`。当前没有新增降雨、地下水补给或食物携水，土壤耗尽后仍需要其他实际水源。

## 支撑与出生投入

真实世界原来按平面身体厚度固定离地高度，长附肢可能持续穿入地面。现在按足端地形接触及累计承重能力确定身体抬升，抬升和关节动作都支付能量；细弱结构不足以承重时不能仅凭腿长举起身体。机械功与生态能量的换算复用现有 `LocalActuationEnergyScale`，不单独给予附肢低价推进。身体高程同步进入生理交换和画面。

幼体初始水量原来受固定核心质量上限限制，高储水能力反而可能导致出生时相对含水极低。现在按实际新生核心容量计算亲本供水，突变后重新检查真实幼体的物质和水预算，投入全部从亲本扣除。规则对水陆一致，不以出生介质授予生存或繁殖资格。

## Godot 检查入口

在项目根目录使用 Godot .NET 启动参数 `-- --stage3-land-demo`。该模式加载人工陆生能力样本并定位首个体，图鉴不持久保存人工结果。普通 F5 不带该参数时仍加载默认水生祖先。

也可在 PowerShell 从项目根目录运行 `./tools/Run-LandDemo.ps1`，它会构建后启动测试窗口；Godot 路径不同时用 `-GodotPath '实际 .NET 版路径'` 指定。

个体生理明细增加“土壤含水”，可对照实际含水、缺氧、足接触和推进观察。

## 实际结果

实际 `SimulationWorld.Step` 人工样本专项 `LAND VIABILITY PASS`，完整输出见 `artifacts/land-viability.log`：

| 检查 | 结果与边界 |
| --- | --- |
| 陆地运动 | 总路径 6.887，约 5.057 个体长；其中关节速度积分仅 0.131，其余包含原有活性表皮推进，不能把总路径全部称为腿走路。关节耗能 1.766e-5、最多 2 个承重接触；关节失活时三项均为 0。 |
| 实际支撑 | 独立附肢对照中强足可抬升 2.3439，细弱足/悬空为 0；世界样本自身不足以完整抬升身体，仍有腹面接地。 |
| 空气交换 | 在陆吸氧 0.4082、10 秒时无缺氧；关闭空气交换后在陆吸氧为 0，并产生真实缺氧。正常样本 67.6 秒首次入水，失活对照 15.5 秒。 |
| 湿土与水账 | 创始体有足接触的陆地时段，整个世界土壤库存实际转移 0.2572；此值并非逐足独占摄水统计。水账误差 1.42e-13，无外加物质。 |
| 保水代价 | 关闭区域屏障和代谢保水后，平均陆地失水率约为原样本的 3.58 倍；该对照未出生后代。不同运动轨迹与接触机会仍会影响整个生存过程，不能只凭此断言适应度排序。 |
| 陆地出生与遗传 | 记录到 1 只实际陆地出生幼体，初始含水 0.82、冻结突变时基因指纹与亲本相同；逐 ID 追踪的陆地最高成熟度为 0.5778，最终死亡，未成熟或再繁殖。 |

因此当前证明的是功能确实进入运动、生理和亲本投入，不是稳定陆生世代已经形成。还没有自然突变建立陆生谱系的证据，人工样本也没有完成从陆地出生到成熟再繁殖的闭环。后续应据实际幼体水合、局部运输、成长支出和食物获取轨迹定位限制，不能用不死、免费补水或强制上岸解决。

回撤专项 `SURVIVAL REFLEX PASS`：关闭初始湿土以隔离原干岸条件，无高级感知的启用组 18.6 秒回水，含水从最低 0.1056 回升至 0.1360；关闭组未回水，末含水 0.0475。判据检验实际回水及水合回升，不要求短窗内固定增加 0.10 的组间差值。

Debug/Release 构建零警告零错误；24 祖先 600 步 `VERIFY PASS`，指纹 `3EBFA0DA46B8F691`、物质误差 -2.36e-11。Godot 300 个体烟测及人工陆生入口 120 帧无窗口启动通过。没有以无窗口测试代替视觉验收，也未重新跑长期生态或声称旧 K 值结论仍适用于本轮。
