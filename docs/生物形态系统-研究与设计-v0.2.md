# 生物形态系统：研究与设计 v0.2

日期：2026-09-08。状态：研究与设计完成；实现按下述检查点推进，不代表系统已经实现。

## 1. 目标与边界

替换方块堆叠式身体表达，支持球形、卵圆形、杆形、弯曲丝状、扁平和分枝轮廓。追求近距离可信、远距离可读、有遗传连续性的低模生命；不承诺真实物种重建或生物学预测能力。

身体区域仍是性质相近的组织区域，不等于一个真实细胞。形态名称只用于观察与测试，不加入 SphereSpecies、Eye、Fin 等物种或器官枚举。禁止统一给所有生物加眼睛、嘴或尾巴。

## 3. 统一数据链

基因与局部发育规则 → 连续形状区域与连接 → 物理几何/体积/暴露表面缓存 → 显示骨架与表皮 → 分级网格。

形状参数建议：三轴比例、圆润度、端部渐细、中心线曲率、连接位置/方向、连接宽度、可选重复/镜像生长规则。所有真实影响身体几何的参数必须进入遗传、合法性校验、指纹和成本计算，不仅藏在渲染随机数中。

- 三轴相近得到球形；一轴增长得到椭球或杆形；短轴压缩得到扁平形。
- 连续中心线弯曲得到弧形和丝状；连接图重复产生分节或分枝。
- 这些是同一参数空间的区域，不是六个可选物种模板。
- 同基因、同发育状态必须生成相同身体；同谱系保留可辨认的比例和色素连续性。
- 现有平面身体拓扑可以先保留，以厚度构成 2.5D 体积；任意三维分枝作为后续能力，不假称本轮已支持。

## 4. 几何与表皮

### 第一层：连续基础曲面

用统一的参数曲面生成器生成低面球/椭球/渐细杆。球形保持圆整轮廓，细长体避免拉长单个粗球导致轮廓尖角；必要时用沿中心线扫掠的截面环。用正确平滑法线保留低面数但减少塑料积木感。限制圆润度、最小厚度和曲率，避免自交和细枝消失。

### 第二层：连接处形成整体外形

同一身体相连的区域使用截面桥接或局部隐式过渡；独立个体绝不共享融合场。主干连续、末端渐细，连接不出现明显穿插球缝。镜像和重复由发育规则决定，不能为了好看强行对称所有生命。

选中/近景个体采用局部隐式场提取或连续扫掠网格；复杂分枝使用受连接关系约束的场，避免整具身体无条件 smooth-union 把相邻枝条焊死。大规模隐式表面实时全体重建不进入 MVP。

### 第三层：材质与动态

以不透明、柔和高光、色素渐变为默认；避免成千上万层透明膜。粗糙度随表面属性变化，微小纹理稳定绑定基因，不每帧噪声闪烁。膜质感属于美术表达，不声称已有真实折射或散射模拟。

允许用当前生长比例/真实激活状态驱动有限形变；停止激活不能仍播放强烈推进动作。周期伸缩须近似保体积，例如纵向缩放 s 时横向两轴各乘 1/sqrt(s)。被动形变与自推进分别记账，渲染变形不额外赋予移动能力。真实低雷诺流体求解和完整行为网络不在本轮。

## 5. 几何必须与模拟一致

先修正当前放大显示造成的体积错觉：世界中的身体尺寸与模拟包围范围用同一尺度，检查器预览可单独放大并标注。不能靠统一 2.4 倍视觉放大再缩小碰撞体使群落挤成团。

- 同物质量与密度限定真实体积；改变长宽比例时重新归一化尺寸，不能白送体积。
- 简单椭球使用 V=4πabc/3，a/b/c 为半轴；复杂体采用确定性的模拟侧几何近似。显示网格不能作为每步模拟输入。
- 原区域盒体体积不能直接沿用为新曲面的物理体积。纯视觉原型可以保留旧账本，但必须标注“几何物理映射尚未迁移”，不能当正式完成。
- 连接重叠不是新增物质：表面融合增加的显示体积受控，正式方案需对区域体积/外壳体积关系校准。遮蔽表面不能重复计入摄取面积。
- 模拟用稳定几何缓存，LOD 只改变显示；切换镜头与网格级别不能改变物质、能量或生存结果。
- 邻域宽相位采用空间哈希，细长身体的接触可用少量球/胶囊代理。不要仅以最长轴的大圆把所有细长生命弹得很远。
- 零距离重叠需要按 ID 稳定打破方向对称；软分离有限速且双方对称处理。出生空间不足可等待或选择合法近邻位置，不能删除生命或随机瞬移到全世界。

## 6. 性能架构与初始预算

| 显示级别 | 建议三角形预算/个体 | 方式 |
|---|---:|---|
| 极远 | 12–40 | 保留主体长宽比和色素的代理体 |
| 普通观察 | 80–320 | 缓存低模身体网格或少量共享区域网格 |
| 近景 | 400–1,200 | 连续表皮，控制同时显示数量 |
| 单个检查对象 | 1,200–3,000 | 连接细节和更好轮廓 |

这是预算起点，不是实测性能承诺。分级采用屏幕投影尺寸和滞回，避免缩放时闪烁；远近形态包围范围一致。按实际场景总三角形与 draw call 预算统筹，不能每个可见个体都用最高级。

MultiMesh 只能批量共享同一网格。不得宣称一个 MultiMesh 能承载每只生物完全不同的拓扑。采用空间块+可复用网格键分组；键含规范化形态、显示生长阶段与 LOD，数量有界、带 LRU 淘汰。若变异导致唯一网格过多，非选中对象退回共享区域曲面或参数形变，保证不会出现数千个批次。

隐式网格只在出生/拓扑变异/跨显示生长档位时重建，使用有界工作队列；线程仅生成普通顶点数组，Godot 资源在主线程上传。队列未完成保留上一级代理，不阻塞模拟也不漏显选中对象。

## 7. 实施检查点

### A：形态样本台（下一处人工检查点）

在 Godot 中建立独立诊断场景，展示同一生成器的球、卵圆、渐细杆、弯曲丝、扁平体、三分枝六种参数样本；可旋转、近看、切换线框/LOD，标注三角形数与参数。多区域至少一个样本应真正连接平滑，不能全是椭球堆叠。

这些是人工构造的几何测试输入，明确标“形态测试样本，非自然演化结果”。不注入正式世界或替换共同祖先。先只交付该视觉原型，连同原相机/UI修复供用户检查，停止等待确认。

### B：接入遗传和物理几何（A通过后）

加入必要可遗传形状参数，统一体积、表面积、碰撞代理与外观；真实生长与后代形态连续。已有世界默认参数保持兼容，任何改动使旧指纹失效都要记录版本原因。

### C：群落与性能（B通过后）

接入分级显示、有界缓存和真实接触/基础运动，检查拥挤群落及显卡表现。每一步结束都停止，不自动推进。

## 8. 最小验收

- 视觉：近看可分辨球/杆/扁平/分枝；连接自然；无方块堆、无随机粘连、无明显地形穿插。
- 遗传：同基因同状态生成一致结果，小突变是小变化，结构突变有可追踪差异。
- 数值：体积/物质匹配，缓存重算一致，数值有限；零能量不产生主动运动。
- 显示：切换相机/LOD后同模拟输入校验值不变；网格缓存与分组数有上限。
- 生物学表述：样本台不是进化证据，基础自推进不是完整微生物流体学，形态多样不是自动证明生态适应。
