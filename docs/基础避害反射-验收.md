# 基础避害反射

## 目的与边界

所有个体具备基础的自身生理反馈：缺氧、脱水或受到新的损伤时，尝试离开令状态恶化的位置。此反馈独立于高级化学感知和视觉；它不提供远处的食物、水域或敌人坐标。

避害方向利用个体自己的近期经历和状态变化。水生个体离水后恶化，可以尝试沿近期来路回撤；不同呼吸能力的个体以实际生理是否缓解为准，不统一强制趋水。无可用经历时需要试探，不能保证每次脱险。

反射影响运动控制意图，实际转向、推进和升降仍由身体结构、局部能量及介质力学执行。不会直接改位置、补能量、解除缺氧损伤或保证种群存活。

初次沿岸对照发现，单球形身体仅靠横向收缩难以在致死前完成掉头。为此允许已有活性表皮在反射期间沿已知的回撤方向施加滑移：方向变换到身体局部坐标，幅度仍受原表达、暴露和介质耦合约束，仍按滑移速度平方支付能量，再进入原力与力矩求解。普通探索沿用原推进方向，附肢继续由自身关节执行。

每个个体仅保存固定大小的短期状态，不扫描远处环境、不搜索全图路径。方向保持、累计压力趋势及未改善超时重试避免逐帧左右反转或永久坚持无效试探；近期缓解信息会过期。

## 玩家检查

重新按 F5 运行，选择靠岸或受伤个体。简洁面板会显示“正在避害回撤”或“正在寻找缓解方向”；展开生理明细可查看生理压力和避害模式。观察实际位置、浸没、含水及缺氧缺口的变化。传送会清除旧方向记忆，因此刚传送且没有经历的个体只能试探，不会凭空知道水在哪里。
