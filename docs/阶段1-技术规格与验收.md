# 阶段 1：遗传与发育

状态：实现与短程自动验证完成，等待用户亲自验收。范围只覆盖开发文档第 18 节的阶段 1。

## 技术规格

- 基因组由局部区域规则组成：出现成熟度、相对父区域的几何、连续材料属性，以及几何、物质、信号三类连接。基因组注册表按完整内容去重；无突变繁殖复用同一基因组 ID。
- 身体是 `1–32` 个无语义材料区域构成的图。代码中没有器官、职业或物种模板枚举。唯一核心区域必须保留；三类连接都必须存在、最终连到核心且无循环。
- 新生体只有已由亲代支付物质的核心区域。其他区域按局部出现时机与成熟度逐步生长；每份新增身体物质都等量扣除储存物质，并支付对应生长能量。
- 当前身体的几何、材料属性和连接共同导出宏观缓存，包括质量、质心、转动惯量、表面积、阻力、浮力、刚度、薄弱连接、摄光表面、物质摄取表面、催化表面、储存容量、维护与激活成本、包围半径、物质及信号连通度。
- 世界步进实际使用缓存结算摄光、环境物质摄取、储存上限和维护成本。繁殖转移核心物质并继承或突变基因；死亡把当前实际身体物质和储存物质全部沉积为残骸。
- 突变使用与环境、放置和繁殖偏移分离的显式 PCG32 随机流。自然繁殖以小变异为主，支持连续数值扰动、区域复制、非核心区域删除、合法改连。每次变异后都执行拓扑与数值验证。

主要实现：

- `src/NativeEpoch.Simulation/Genetics.cs`：基因、注册去重、合法性验证和四类突变。
- `src/NativeEpoch.Simulation/BodyDevelopment.cs`：付费发育、无语义区域图和宏观缓存重算。
- `src/NativeEpoch.Simulation/SimulationWorld.cs`：遗传与发育接入生命循环和物质账本。
- `src/NativeEpoch.Headless/Program.cs`：阶段 1 自动验证、强制突变诊断和谱系检查输出。

## 人工验收命令

在项目根目录执行：

```powershell
dotnet run --project .\src\NativeEpoch.Headless\NativeEpoch.Headless.csproj -c Release -- --verify
dotnet run --project .\src\NativeEpoch.Headless\NativeEpoch.Headless.csproj -c Release -- --diagnose-mutations --seed 20260908
dotnet run --project .\src\NativeEpoch.Headless\NativeEpoch.Headless.csproj -c Release -- --seed 20260908 --steps 300 --ancestors 4 --report-every 100 --inspect-lineage 6
```

第二条命令明确属于测试模式：它强制各执行一次数值、复制、删除和改连，用于覆盖拓扑安全检查，不代表自然模拟中的发生频率。

第三条命令会先输出人口、基因组数、实际身体区域数、平均成熟度和物质账本，再展示近期亲子记录。相同基因组 ID 表示准确继承；不同 ID 及突变摘要显示连续或拓扑差异；存活后代同时显示其发育状态和缓存数据。

## 限制与阶段门

- 这里验证遗传连续性、发育付费、拓扑安全、缓存一致及生命循环接线，不代表完成数百或数千代长期演化、5,000 个复杂身体性能或跨平台逐位确定性。
- 本阶段没有行为控制网络、主动运动、复杂接触与捕食、物种聚类、三维表现或 Godot UI；这些属于后续阶段。
- 阶段 2 至阶段 5 均未授权。用户明确验收阶段 1 前不得继续。
