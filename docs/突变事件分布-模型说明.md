# 突变事件分布：模型说明

## 模型目标

游戏中的一个“突变事件”表示一个可观察的高层表型参数或拓扑变化，不表示现实生物的一次 DNA 碱基变化。该模型用于保持子代通常接近亲代，同时允许少量多事件、结构变化和罕见大幅变化进入自然选择。突变可以有利、中性或有害，实现不按环境需求定向生成功能。

突变效应分布会随物种、突变类型、性状和环境改变，很多可观察变化是小效应，但不存在一个能直接搬到所有生物和所有尺度的固定真实分布。参考：[PLOS Biology 2024](https://journals.plos.org/plosbiology/article?id=10.1371/journal.pbio.3002698)。本项目的百分比是可解释、可调试的游戏层模型，不声称复刻现实 DNA 突变次数。

## 子代的任意突变概率

对亲代 `MutationRate = p`，先保留旧版两个独立通道“至少一个发生”的概率：

`oldAny = 1 - (1 - p) * (1 - 0.55p)`

当 `p = 0` 时，子代精确继承，概率为 0。当 `p > 0` 时，新概率为：

`newAny = min(0.95, oldAny + 0.05)`

这使整体突变概率仅比旧版高 5 个百分点：

| `p` | `newAny` |
|---:|---:|
| 0 | 0% |
| 0.22 | 36.438% |
| 0.28 | 44.088% |
| 0.32 | 48.968% |

代码中的单一真值入口是 `GenomeMutator.NaturalMutationProbability(double mutationRate)`，UI 应调用它，不再自行重复概率公式。

## 条件事件数

只在本次子代已抽中任意突变后，再抽取事件数：

| 事件数 | 条件概率 |
|---:|---:|
| 1 | 90% |
| 2 | 9% |
| 3 | 1% |

典型祖先 `p = 0.28` 时，每出生一个子代的理论分布为：无事件 55.912%，一事件 39.6792%，两事件 3.96792%，三事件 0.44088%。

`MutationResult.EventCount` 是实际改变了指纹的事件数，`EventKinds` 按顺序保存实际事件类型。旧 `Kind` 保留为最后一个实际事件，用于兼容原有记录和 UI。如果尝试的变化没有改变基因组指纹，它不会被记为真突变。

## 事件类型与幅度

每个已抽中的事件独立选择：

- 85% 是局部单标量变化：区域连续参数、代谢参数、一个控制权重或一个感知标量。
- 15% 是结构类变化：区域复制/删除/重连，控制节点增删/重连，感知频道或感知源/目标连接改变。

在局部标量事件中，98.5% 使用标准化 1–4% 的小步长，1.5% 使用罕见大幅步长。因为结构事件占 15%，罕见大幅标量突变占全部事件约 1.275%。`SensorPoint` 严格只改变 `Gain`、`ResponseRate`、`DirectionOffsetRadians`、`Range` 或 `DirectionalSelectivity` 中的一项；`Channel`、`SourceRegionId` 和 `TargetControllerNodeIndex` 只在稀少结构类事件中改变。

典型祖先每个出生子代至少含一个结构事件的理论概率约为 7.2231%。该数字未扣除当前拓扑下不可用而回退为局部变化的结构尝试。

## 固定亲代诊断

`MutationDistributionDiagnostics.Run()` 直接对同一个固定祖先调用 `GenomeMutator.Inherit`，默认抽样 10,000 个子代。该诊断不把子代递归当作下一代亲代，因此不会无界增长区域、控制节点或感知槽数。

诊断需同时验证：任意突变概率，条件事件数，85%/15% 事件分类，罕见大幅比例，单局部事件只改一个标量，`SensorPoint` 不改频道或连接，事件元数据一致，所有子代拓扑合法，真突变必须改变指纹，以及零突变率的精确继承。
