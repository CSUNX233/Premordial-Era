# 阶段 0：无画面生命循环

状态：实现与短程自动验证完成，等待用户亲自验收。范围只覆盖开发文档第 18 节的阶段 0。

## 技术规格

- `NativeEpoch.Simulation` 是不引用 Godot 场景、节点或渲染 API 的纯 C# 模拟核心；`NativeEpoch.Headless` 是命令行入口。
- 世界坐标为 `512 × 512` 浮点连续空间。环境内部使用默认 `128 × 128` 隐藏采样阵列，所有光照、温度、湿度、矿物和残骸查询均经双线性插值。
- 调度器只接受固定 `0.1` 秒步长。环境生成、祖先放置和繁殖偏移使用从命令行种子派生的显式独立 PCG32 随机流。
- 阶段 0 生物只有文档允许的固定身体参数。每步结算光能摄取、矿物/残骸物质摄取、维护、无性繁殖和死亡；本阶段没有基因、发育、器官枚举、行为网络或表现层。
- 矿物、残骸、身体物质和储存物质共用物质账本。繁殖从亲代转移身体物质，死亡把全部身体与储存物质沉积为残骸。模拟运行期间不生成物质，也不硬删活体来控制数量；达到可配置人口安全上限时仅暂停新的繁殖。
- 光是明确的外部能量输入；维护、繁殖开销和能量上限溢出计入耗散统计。能量不纳入物质守恒式。

实现位置：

- `src/NativeEpoch.Simulation/SimulationWorld.cs`：固定步生命循环、物质回收和确定性状态指纹。
- `src/NativeEpoch.Simulation/EnvironmentField.cs`：隐藏采样阵列与连续双线性查询、摄取和残骸沉积。
- `src/NativeEpoch.Simulation/SimulationSnapshot.cs`：人口、能量、物质和有限数值统计。
- `src/NativeEpoch.Headless/Program.cs`：无画面运行入口、负载参数和内置验证。

## 运行与验收

环境要求：.NET SDK 9。当前机器检测到 `9.0.304`。Godot 完整路径实测版本为 `4.7.2.stable.official.ed1daf0bf`，但 `project.godot` 只声明 `4.7` 与 `Forward Plus` feature，未声明 C#/.NET feature。因此本阶段只验证独立的纯 C# 无画面核心，未声称通过 Godot C# 编辑器构建。

```powershell
dotnet run --project .\src\NativeEpoch.Headless\NativeEpoch.Headless.csproj -- --verify
dotnet run --project .\src\NativeEpoch.Headless\NativeEpoch.Headless.csproj -- --seed 20260908 --steps 600 --ancestors 4 --report-every 100
```

验收时应看到：

1. `--verify` 报告相同种子指纹一致、出生数与死亡数均大于零、所有数值有限、物质误差在容差内。
2. 普通运行每隔指定步数输出时间、存活数、累计出生/死亡、环境矿物、残骸、生物物质和物质误差。
3. 可用 `--steps`、`--ancestors`、`--seed`、`--grid`、`--world-size`、`--max-population` 和 `--report-every` 调整短程负载。
