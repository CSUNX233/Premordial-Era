# 功能图鉴

按 **G** 或点击工具栏“功能图鉴”打开；再次按 G、Esc 或点击关闭退出。阅读期间自动暂停世界，关闭后恢复之前的暂停状态。

- 左侧列出运行中观察到的功能；选中后查看作用证据、首次观察时间与代数、基因指纹和最近代表个体。
- 点击“收藏”标记关注的功能，“只看收藏”用于筛选。收藏及历史保存在 Godot 用户数据目录下的 `observed-functions-v1.json`，重开程序或重置世界仍保留。
- “定位代表个体”跳转到当前世界仍存活、基因指纹匹配的代表。历史世界的重复 ID 不会被误选；个体已死亡时记录仍保留。
- 资源和温度笔刷可改变选择压力。比如形成稀疏资源斑块后，观察感知和移动的收益是否足以支付能耗，再跟踪后代。收藏本身不授予技能，也不保证有利突变。

图鉴按运行快照定期采样，所以时间表示首次被观察到的时刻，并非精确到模拟步的功能起源。初始祖先已有的作用也会记入图鉴；第 0 代记录不是新突变。它记录功能与功能组合，而非给预制物种解锁器官。

“观察到作用”只证明个体实际产生过相应信号、推进或供氧。不能据此声称这个功能有适应优势：后者需要同环境下的跨代繁殖与失活对照。空气摄氧可能来自皮肤；气腔供氧单独记录。方向光感属于简单视觉，尚不是图像识别。

性能边界：每秒读取一次已有展示快照；历史最多 256 项，每项最多 32 个基因示例；普通运行每 30 秒保存，收藏操作及退出时保存。诊断和截图运行不污染玩家存档。
