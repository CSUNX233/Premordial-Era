# 长期衰退：矿物竞争修复验收

用户反馈默认24只、未改环境，约2000秒团灭。当前代码/默认种子20260908未复现同一时刻归零，但复现了显著衰退：600秒79只，2000秒18只，2100秒15只，仅第6代。全世界此时仍有835藻类与3376植物，不能解释成“食物全部消失”。幼体死亡时储存底物低，但平均仍有能量；低水合是另一个风险。

## 已证实并修复的问题

原Step先执行环境UpdateProducers，再给个体ReserveMinerals。低矿物格里，植物/藻类可先吃完每步刚回流的矿物。默认祖先光合表达强、摄食较弱，因此既分不到光合建材，也不能充分依靠吃植物填补缺口。固定低矿格对照中，原顺序个体获矿0，按需求共同竞争后获得约1.997e-6，仍来自原有库存。

现在在环境生产者更新前，按个体实际光吸收请求及储存空间估计矿物需求。同格环境生产者与个体按需求比例分享有限矿物，环境生产者的整步预算在子步间共享，不能反复占用留给个体的份额；随后个体继续使用原有有限预留及退款。光能仍按实际环境生产消耗记账，没有重复供光、补矿或保底出生。无个体竞争的格子保持原处理。
