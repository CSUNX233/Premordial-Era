# 新器官与新功能：实现路线（首轮集成完成）

2026-09-09：组织表达与感知接口、简单视觉、三维附肢、气腔与肺样呼吸已全部接入正式世界，功能图鉴与后台模拟已接入。短测结果见 [本轮验收](组织与器官-本轮验收.md)。本轮完成后等待玩家检查，不自动继续物种定义或长期适应实验。

用户希望突变能产生视觉、肺、可用的腿，并让功能差异接受自然选择。本轮补齐了方向光感、接地关节和气腔通气的工程规则；目前没有证明完整新器官在自然种群中的长期适应优势。

核心限制：模拟只能产生已建模的物理和生理规则允许的功能。需要先实现低层能力，再让遗传变化组合出组织结构；不能指望给现有浮点参数增加噪声，就出现此前不存在的感光、通气或承重机制。

## 表示与因果链

同时接入功能图鉴：按实际感知、接触推进、通气供氧等运行证据记录功能，收藏与历史存到本机，可定位当前世界的代表个体。玩家可依据图鉴使用已有环境工具观察后代，收藏不改写基因；自然选择优势仍需要跨代对照。

扩展区域基因的组织表达程序，使其可遗传地决定：局部受体/交换通道/收缩/屏障等属性、方向与空间分布、发育时序，以及信号、物质、机械连接。突变允许复制并分化组织、改变连接或调控，仍受材料、能量、维护与信号处理成本约束。

所有功能必须经过 `遗传 → 付费发育 → 局部物理/生理 → 感知与控制 → 生存/成熟后代数`。器官名称用于事后描述已具备的功能，不作为直接发放能力的开关。部分突变可能中性或有害，不能保证所有突变都有收益。

## 三个具体实现

| 功能 | 要补的底层机制 | 模拟中可允许的逐步组合 | 验收 |
|---|---|---|---|
| 视觉 | 有朝向的光感受体、遮挡与角分辨率、可遗传信号输入连接 | 光敏区域 → 有遮蔽的方向性受体 → 多个不同方向的受体阵列 | 相同环境中，受体能影响趋光/躲避/发现目标；遮住或断开信号后失去相应效果 |
| 肺样呼吸 | 有限容量的内部气腔、与外界相连的开口、气体交换面、通气驱动与向身体运输氧的连接 | 内陷交换面 → 保留空气的腔体 → 能刷新空气并向组织供氧的结构 | 消耗腔内氧后必须换气；封闭开口或断运输后不能持续供氧；水下不能凭空获取空气 |
| 可用的腿 | 三维局部关节、收缩力矩、足端与地形接触、摩擦/支撑，以及控制反馈 | 凸起或附肢 → 可摆动连接 → 能接地承重和推进的附肢组合 | 抬离地面、关节断开或无能量时推进衰减；不能把腿数直接乘成速度 |

这些是允许的工程路径，不是对真实物种历史单一路径的断言。视觉还要把现有固定范围的环境采样与真实视觉区分开；不能所有个体先免费获得完整视觉，再让眼睛成为装饰。

视觉初期只做少量方向光信号，不为每个生物渲染一台摄像机；肺用小型气腔与交换网络，不做完整流体；腿先做少数接触点和局部关节，不给每块组织建立高成本刚体。感知/求解预算保持固定并与相机可见性无关。

## 实施顺序与选择验证

按组织表达与感知接口、方向光感、三维附肢接触、气腔/通气的依赖顺序实现；各模块可并行开发、统一接入正式世界。本轮按用户最新要求全部完成后再交给用户检查。

先证明同一遗传结构能实际改变能力，再进行同环境、多代、祖先/后代/功能失活对照，比较成熟后代数及生态位置。识别持久分化的谱系可以先作为游戏中的生态类型；当前无性繁殖体系不能直接套用“生殖隔离已出现”的物种形成结论，也不能以外观不同直接宣布新物种。

有限资源和接触可以让生物走向或被推向岸边，但环境压力本身不生成定向突变。编码应允许局部受体、收缩/支撑、屏障/交换等中间组合逐步改变作用，使完整新功能不依赖一次碰巧出现整套预制器官。表达、连接、形态和成本共同影响生存；不强制每一条谱系都走上陆地，也不删除无用形态以美化结果。

发育与控制的联合编码参考 [Sims 1994](https://www.karlsims.com/papers/siggraph94.pdf) 与[发育—演化反馈模型（2021）](https://www.frontiersin.org/journals/robotics-and-ai/articles/10.3389/frobt.2021.674823/full)。本项目采用有界区域和连续表达的工程近似，不复刻整套基因调控网络或细胞级发育求解；仍须通过实际失活/遗传对照证明各条功能链。

参考：[Nilsson & Pelger 1994，眼的渐进光学模型](https://lup.lub.lu.se/search/publication/1728468)；[Karl Sims 1994，联合遗传身体结构与控制网络](https://www.karlsims.com/papers/siggraph94.pdf)。这些研究支持采用可逐步改变的结构与控制表示，不保证本项目会自动产生复杂器官。
