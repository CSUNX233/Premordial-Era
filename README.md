# 原生纪

一个使用 **Godot .NET / C#** 开发的生命演化模拟原型。生物从一批形态与基因不同的基础水生祖先开始，通过遗传、突变、付费发育和有限资源竞争，形成不同的身体与能力组合。

项目目前处于可运行 MVP 阶段。已实现生命循环、基因驱动低模身体、主动探索、局部生理与空间竞争，以及可遗传组织表达、方向光感、三维附肢和气腔供氧。自然选择由个体的存活与实际繁殖产生，不按代数解锁预制物种。

## 当前可以体验什么

- **有限环境**：有深浅层次的水域、陆地、光照、矿物、有机物及氧交换。摄取会扣除资源，死亡残骸与代谢废物进入循环。
- **完整生命循环**：幼体逐步消耗物质和能量长大，成熟后才可繁殖；亲代承担投入，存在夭折、损伤和衰老。
- **可遗传身体**：区域形态、材料、生理和控制参数可以点突变，区域可以复制、删除和重新连接。变化会影响能力和成本，而不仅是颜色。
- **随机水生祖先**：每个初始个体独立生成 1–4 个区域的遗传方案，长宽、扁度、曲率、分枝、材料、代谢与基础控制基因均有差异；年龄和成熟度从 0 开始，全部投放在合法水深。初始不带方向视觉、可用关节或气腔。相同种子可重复，初始差异不算作运行中新出现的突变。
- **真实探索与互动**：健康个体主动探索；低能量个体减少活动。接触可引发退让或付费争位，拥挤时无法容纳新生身体就暂缓繁殖。
- **观察工具**：查看个体、亲代、代数、身体库存、发育、环境、接触压力和食物满足率；支持暂停、单步、时间倍率及环境笔刷。
- **低模展示**：近景连续表皮、远景简化代理和视野裁剪；相机可见性不改变生命模拟规则。
- **可组合功能**：组织与受体需付费发育；方向光感受朝向、地形与身体遮挡限制；附肢依靠局部关节、接地和付费功推进；气腔只有实际开口接触空气才能补气，并依靠交换与运输供氧。
- **功能图鉴**：查看观察到的功能及组合，收藏、筛选、定位代表个体，记录首次代数和基因指纹。历史与收藏保存在本机，收藏不改写基因。

形态实验室中的六种形状是人工诊断样本，用于检查基因到几何的映射，不能当作自然演化已经产生六个物种的证据。

## 运行

已验证环境为 **Godot 4.7.2 .NET（Mono）** 与 **.NET 9 SDK**。项目依赖 `Godot.NET.Sdk/4.7.2`，目标框架为 `net9.0`，需要使用 .NET 版编辑器。

```sh
git clone https://github.com/CSUNX233/Premordial-Era.git
cd Premordial-Era
dotnet build NativeEpoch.csproj -c Debug
```

在 Godot .NET 中导入根目录的 `project.godot`，按 **F5** 运行。修改代码后应停止旧实例并重新运行。当前已验证的图形环境为 Windows / D3D12；其他平台的渲染后端尚未完整验证。

默认投放 24 个祖先；“300 生物观察”使用同一初始物质预算，并先执行 8 秒真实模拟，适合观察较密集的群体。

祖先先显示自己的幼体核心，再逐步长出基因编码的其他区域。拉近后能查看形状差异，远景仍使用简化代理。开发诊断可传入显式 `founderGenome` 或设置 `RandomizeFounders=false`，恢复统一祖先用于对照；正常游戏默认随机。

子代突变概率比旧模型增加约 5 个百分点。初始谱系约为 **36.4%–49.0%**，典型遗传参数 `MutationRate=0.28` 时约 **44.1%**。触发后，一次/两次/三次事件的抽样比例为 **90% / 9% / 1%**；其中 85% 为局部单参数事件，15% 为结构事件（身体区域、控制拓扑或感知连接变化）；局部事件主要采用小步长。零突变率仍精确继承。无效、未改变基因的尝试不计作实际突变，个体检查器显示实际出生突变次数和它的子代概率。这是游戏高层性状参数的分布，不是 DNA 碱基突变率。

## 无窗口诊断

纯模拟核心不依赖 Godot，以下命令可以直接运行：

```sh
# 确定性、守恒、发育、局部生理和力学回归
dotnet run --project src/NativeEpoch.Headless/NativeEpoch.Headless.csproj -c Release -- --verify --seed 20260908 --steps 600 --ancestors 4

# 真实探索与低能量休息
dotnet run --project src/NativeEpoch.Headless/NativeEpoch.Headless.csproj -c Release -- --diagnose-movement

# 占用、付费接触、空间受限出生和有限食物分配
dotnet run --project src/NativeEpoch.Headless/NativeEpoch.Headless.csproj -c Release -- --diagnose-competition

# 观察实际代数、出生/死亡、资源与守恒；此例为模拟时间 300 秒
dotnet run --project src/NativeEpoch.Headless/NativeEpoch.Headless.csproj -c Release -- --diagnose-ecology --seed 20260908 --ancestors 24 --steps 3000 --report-every 1000
```

`VERIFY PASS` 表示该组诊断通过，不代表所有场景、性能或自然适应已经得到证明。更多选项见 `--help`。模拟采用固定 0.1 秒步长，命令行默认祖先数量与图形界面默认数量不同，应显式传入参数。

## 承载量与性能

默认资源预设以 **约 1000 只**为承载目标。加入组织表达前的基线版本，默认种子 `20260908`、24 祖先无干预运行到 1800 / 2100 / 2400 秒时，种群分别为 **932 / 929 / 975**。这不是新增组织成本后的 K 保证；统一祖先版本短测到 120 秒有 55 只存活、17 个基因组，新增功能后的长期承载量尚未重新校准。

图形界面的 **5000 只**是程序安全上限，不是生态承载量。初始投放 24 或 300 只时，总物质预算相同；更多祖先所需的物质从环境中支取。

性能优化包括后台模拟、缓存复用、受限后台网格构建、近远分级与视野裁剪。随机祖先与精度折中加入之前，1000 祖先模式的实际 D3D12 窗口采样维持约 1×，帧时间平均 3.35 ms、P95 4.74 ms、最大 23.16 ms（约 996 活体、30 秒采样）。这不代表任意种群和复杂形态都能稳定 60 FPS；核心单步约 38.3 ms，仍有较高内存分配。新增功能采用有界传感、少量接触点和局部库存，不为每个生物渲染摄像机或求解完整流体。

详细数据见 [K 校准记录](K约1000-调参记录.md) 和 [空间竞争与个体互动验收](空间竞争与个体互动-验收.md)。

## 演化功能路线

以下功能已接入正式世界，并通过针对性失活、遗传与守恒短测：

1. **组织表达与感知接口**：局部组织属性、受体和传感到控制的连接可遗传，实际表达受发育、连接与能量约束。
2. **简单视觉**：有朝向和遮挡的少量光信号；无受体、断信号或缺少能量时功能受限。
3. **三维附肢**：局部关节、收缩、支撑与地形接触产生推进；附肢外观本身不提供速度奖励。
4. **气腔与肺样呼吸**：有限气腔、开口、通气与运输连接共同供氧；水下不能凭空补充空气。

可分别运行 Headless 参数 `--diagnose-tissue`、`--diagnose-vision`、`--diagnose-appendage`、`--diagnose-cavity`。图形端增加 `--stage3-worker-smoke`，验证后台计算与同步计算的状态指纹一致，并检查暂停、笔刷与重置串行化。

主循环使用单个后台模拟批次，画面只读取完成后的快照；相机查询静态地形缓存。没有改变固定步长或跳过生态计算。每个批次最多约 8 ms（单步本身可能更长），避免高倍速一直占住界面。新增精度配置保留 `CorePrecisionProfile.Reference` 对照，并使用 `Balanced` 执行有限精度折中；守恒与遗传检查不放宽。

目标是让奇怪、不对称、无用或有害的遗传组合也能出现，并通过实际生存和后代数量受到筛选。被挤到岸边可以形成选择压力，但不保证某一谱系必然长出腿或肺。当前尚未证明完整的新器官自然涌现、长期陆生适应优势或物种形成。

设计与进度见 [新器官与新功能路线](新器官与新功能-实现路线.md) 和 [MVP 调度](MVP-调度.md)。

图鉴操作见 [功能图鉴说明](功能图鉴-使用说明.md)，气腔因果链及限制见 [气腔实现与验证](气腔与肺样呼吸-实现与验证.md)。

祖先诊断：Headless 参数 `--diagnose-founders`；精度局部作用对照：`--diagnose-precision`。整体计算耗时必须与完整世界对照，不能把某个模块的节约比例当作整个游戏的收益。

精度对照与随机祖先实测见 [随机祖先与精度预算验收](随机祖先与精度预算-验收.md)，突变分布见 [模型说明](突变事件分布-模型说明.md)。可分别运行 --diagnose-founders、--diagnose-mutation-distribution、--diagnose-precision 和 --diagnose-world-precision。完整 Step 对照耗时降低约 11.96%，该工作负载主要生态输出最大偏差约 0.87%。
